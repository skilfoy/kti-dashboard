# KTI on Oracle Cloud (Always Free)

Neon's Free plan allows 5 GB a month of query results through its proxy and suspends compute past it; the collector
reads about 270 MB a day (18 November 2026). Oracle's Always Free tier includes 10 TB of outbound transfer a month, so
the database moves to an Always Free Ampere A1 server in the KilfoyCyber tenancy (home region us-chicago-1). The
collector, its bucket and its schedule stay on Neon.

## Pieces

- `bootstrap.sh`: cloud-init user data. Postgres 17 on the local socket only, the SQL gateway (`sqlgw/`), SearXNG on
  localhost, Caddy with automatic HTTPS on `<public-ip>.sslip.io`, host firewall for 80/443, nightly `pg_dump` (7 kept),
  fail2ban, unattended upgrades. `ROLE=all|db|search` selects the services; memory settings follow the server size.
  Tokens are generated on the server into `/etc/kti` (root-only): `sqlgw.env` (gateway bearer token) and `searx.env`
  (the secret SearXNG path).
- `sqlgw/server.mjs`: answers the Neon SQL-over-HTTP contract (POST /sql, one statement or a transaction, raw text values,
  array rows) so the collector changes only `TI_SQL_URL` and `TI_SQL_TOKEN`. Peer authentication as OS user `kti`; no
  database password exists.
- `post-setup.sh`: the memory floor for Oracle's idle-reclamation rule (A1 only) and `/usr/local/bin/kti-migrate`, which
  copies schema `ti` from Neon (the connection string is read from the terminal and never stored).
- `provision.sh`, `micro.sh`: Cloud Shell scripts for the network and instances.

## Capacity

Chicago A1 capacity was exhausted in all three availability domains on 18 November, and this tenancy's limit for AMD
micros is zero. The collector's `ocia1` job (`neon/parts/37j-oci.mjs`) asks for the A1 server in every slot until a
launch succeeds, then stops. Its API key is generated by the job; the private half stays in the bucket
(`secrets/oci-launcher.pem`), and the public half is registered on the Oracle user `kti-launcher`, whose group may only
manage instances and use the network. Settings live in `ops/oci-a1.json` in the bucket.

Never stop the A1 instance: a stopped Always Free instance restarts only when capacity exists. Reboot instead.

## Cutover

1. SSH from Cloud Shell (`ssh -i ~/.ssh/kti ubuntu@<ip>`), `sudo bash post-setup.sh`, then `sudo kti-migrate`.
2. Replay an hour of collector cycles against the gateway; every job must finish within half its lease.
3. Deploy the function with `TI_SQL_URL=https://<host>/sql` and `TI_SQL_TOKEN` (from `/etc/kti/sqlgw.env`), and
   `SEARXNG_URL=https://<host>/<secret path>`. Rollback: deploy without `TI_SQL_URL`.
